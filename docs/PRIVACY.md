# 公开下载的隐私边界

- 原始源码仓库继续私有；历史提交和旧的私有发行包存在真实姓名，不向公开下载仓库复制，也不直接把原仓库改为公开。
- 公开下载仓库只包含单独撰写的使用说明和经过校验的 Windows 程序包；不含源码历史、测试、文档截图、正式数据库或备份。
- 程序中原有的真实姓名回归示例替换为虚构编号，旧名单初始化入口已移除。本地已有队员和比赛数据不执行批量改写。
- `scripts/package.ps1` 重新编译程序，再由 `package-public.py` 按允许清单打包；`verify-delivery.py` 重新校验清单、校验值及源码UI一致性。
- 在本机正式数据可用时，公开打包检查 UTF-8、UTF-16LE 中是否含真实姓名、队员ID或联系方式，命中即拒绝打包。私有识别词仅从本机读取，不写入源码或公开说明。
- 每次公开发布都应验证原仓库仍为私有、公开仓库文件清单以及匿名下载文件的SHA256。
- 实际队员名单由管理员通过私下渠道单独交付，公开仓库不代管这类数据。
