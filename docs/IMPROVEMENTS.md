# 初始改进清单与界面对应

内置条目定义在 ui/core/initial.js，稳定ID `builtin-future-N` / `builtin-completed-N`。新安装首次生成与本文件相同的清单；勾选和编辑之后以本机文件为准。

“待改进 → 导出清单”生成 `wku-improvements/v1` 文件。维护者更新该文件的版本、状态和完成说明后，可在“导入更新清单”预览：按ID新增 / 替换，不删除本机额外条目；写入前自动备份。全量备份也包括完整清单。不会因为替换程序文件就静默重置用户勾选。

| 条目 | 初始状态 | 版本 / 依据 |
|---|---|---|
| Windows离线便携程序与本机文件保存 | 已完成 | 1.0.0，实际编译及EXE访问控制、持久化、快照、重启测试 |
| 三类赛制、固定双打与可调规则 | 已完成 | 1.0.0，规则及赛程回归测试 |
| 八人案例与前轮纠错保留后续 | 已完成 | 1.0.0，指定案例及保留后轮逐字段断言 |
| 手机在局域网连接电脑并录分 | 待处理 | 小屏布局已实现；配对、受限权限、真机验证尚未实现 |
| 队员通过公网实时只读查看 | 待处理 | 未实现；不擅自部署公网 |
| 长期积分规则与积分榜 | 待处理 | 未实现；不伪造积分 |
| 轮换搭档双打及个人成绩计算 | 待处理 | 未实现；正式赛事只支持固定搭档 |
| 团体赛 | 待处理 | 未实现 |

用户人工勾选是现场记录，不是测试证据。未来只有实现并完成对应验证，维护文档和版本清单才可标记开发完成。

## 部分实现与限制

- 手机：已做响应式浏览器布局；未实现手机连接电脑录分。
- 扩展低位排名：可手动加正式排位赛并人工确认名次；没有按任意“争夺到第N名”自动生成全部排位树的向导。默认只自动决出前四及实际淘汰轮次区间。
- 阶段规则：支持小组 / 后续阶段覆盖以及逐场修改未开始场次；不批量改写已进行场次的当时规则。
- 晋级示意：按实际阶段显示完整场次；SVG导出保留每个阶段与比分，未实现复杂树形图编辑器。
- 旧版迁移：可查看并保留原始数据，完整交接由新版赛事包承接；因算法和人数不同不自动无损转换旧格式。
- 保存：在录分框中点“保存草稿”或“确认完赛”后立即写文件；仅输入但尚未提交的内容不算已保存。关闭前有清晰说明。
- 安装 / 便携包：已在当前Windows实机编译运行并重启验证；未在全新、无开发环境的独立Windows电脑上二次安装验证，未做代码签名或自动更新。
