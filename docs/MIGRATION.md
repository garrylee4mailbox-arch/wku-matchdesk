# 旧版迁移清单

已阅读 Downloads 中的《WKU今晚比赛记录程序.html》及 `wku-night-cup/v1` 样例备份；原文件未修改。

| 旧能力 | 新入口与变化 |
|---|---|
| 随机分组 / 手工分组 / 锁定后调整 | 创建时预览随机或指定，确认后管理员调整并保留影响记录；不再固定9人3组 |
| 11分比分校验 | 独立 rules 模块；扩展11/15/21分、三局两胜、领先两分及封顶 |
| 第一 / 第二阶段及晋级展示 | 统计与晋级、完整赛程示意；三类赛制、轮空、任意非整齐人数 |
| 原排序规则 | 不继承旧版“相互胜负优先”；默认胜场→累计得分，保留同分待裁定 |
| 前轮改分时重置后续 | 改为绝不静默重置，保存受影响清单，管理员逐场明确保留 / 作废 / 重赛 |
| 记录员标记 | 本地操作者姓名，非在线账号 |
| 撤销 | 本次20次撤销与跨重启自动快照 |
| 浏览器自动保存 | 改为本机文件原子持久化、保存状态和版本冲突控制 |
| JSON备份与恢复 | 单届完整包、全量备份、导入验证 / 冲突预览 / 恢复前自动备份 |
| 含进度网页交接 | 以完整赛事包承接；拷贝到另一台电脑导入继续 |
| CSV / 打印 | 全阶段CSV、可打印报告、完整SVG赛程；结果前四不删低位记录 |
| 固定十人的趣味赛 | 手动新增任意参赛单位对阵，独立标记，不影响正式名次 |
| 当晚9人名单 | 可选初始化已知姓名，性别未知、可编辑；不假定为完整校队名单 |
| 旧备份导入 | 只读查看并保留完整原始JSON到全量备份；不强行无损转换不同赛制 |

新版分组预览支持逐人锁定组别；重新随机仅调整未锁定者，锁定人数超过均衡组容量时明确提示。
