# 版本日志

## 1.0.0 · 2026-10-24

- 新建多模块离线比赛工作台，Windows 自带 .NET Framework 运行，无第三方运行库、登录或CDN。
- 固定 / 临时队员库、稳定ID、名单快照、固定双打配对、男女共赛设置。
- 循环、同名次赛、淘汰赛，非整齐分组、逐人锁定、轮空、交叉半决赛和季军赛。
- 11/15/21分、三局两胜、领先两分、封顶，草稿与正式成绩分开。
- 默认胜场→累计得分，同分转人工，加赛不递归进入原组小分。
- 人工晋级与真实战绩分开；前轮改分保留后续，影响清单逐项处理。
- 管理员配置、分组、增删未进行比赛、迟到补充名单、双打替补、状态策略。
- 独立趣味活动可安排单打 / 双打，不要求固定十人，不影响正式名次。
- 明确 / 并列 / 未决 / 退赛 / 近似名次，归档修订保留版本，个人与组合历史查询。
- 本机原子文件保存、修订号保护、最近100个自动快照、撤销、CSV、打印PDF、SVG、完整赛事包、全量备份。
- 旧版 JSON 只读查看及原文保留，不自动采用旧版排序。
- 独立待改进页面，条目版本、说明、完成 / 撤销完成、筛选、单独导入更新清单，与备份一同保存。

数据 schema v1；当前无须跨版本迁移。未知版本拒绝覆盖。完整测试记录见 VALIDATION.md。

## 归档界面修正 · 2026-10-24

- 修复绿色成绩栏内归档按钮白底白字的问题。
- 未确认最终成绩时显示“待最终确认”，避免与统计结果已确定混淆。
- 点击归档会先引导确认成绩；有待处理改动时直接定位管理员清单。
- 明确保留已有安排与比分时，不再清空刚确认的最终成绩；作废或重赛仍需重新确认。
