# 版本日志

## 1.0.0 · 2026-10-24

- 新建多模块离线比赛工作台，Windows 自带 .NET Framework 运行，无第三方运行库、登录或CDN。
- 固定 / 临时队员库、稳定ID、名单快照、固定双打配对、男女共赛设置。
- 循环、同名次赛、淘汰赛，非整齐分组、逐人锁定、轮空、交叉半决赛和季军赛。
- 11/15/21分、三局两胜、领先两分、封顶，草稿与正式成绩分开。
- 默认胜场→累计得分，同分转人工，加赛不递归进入原组小分。
- 人工晋级与真实战绩分开；前轮改分保留后续，影响清单逐项处理。
- 管理员配置、分组、增删未进行比赛、迟到补充名单、双打替补、状态策略。
- 独立趣味活动可安排单打 / 双打，不要求固定十人，不影响正式名次。
- 明确 / 并列 / 未决 / 退赛 / 近似名次，归档修订保留版本，个人与组合历史查询。
- 本机原子文件保存、修订号保护、最近100个自动快照、撤销、CSV、打印PDF、SVG、完整赛事包、全量备份。
- 旧版 JSON 只读查看及原文保留，不自动采用旧版排序。
- 独立待改进页面，条目版本、说明、完成 / 撤销完成、筛选、单独导入更新清单，与备份一同保存。

数据 schema v1；当前无须跨版本迁移。未知版本拒绝覆盖。完整测试记录见 VALIDATION.md。

## 归档界面修正 · 2026-10-24

- 修复绿色成绩栏内归档按钮白底白字的问题。
- 未确认最终成绩时显示“待最终确认”，避免与统计结果已确定混淆。
- 点击归档会先引导确认成绩；有待处理改动时直接定位管理员清单。
- 明确保留已有安排与比分时，不再清空刚确认的最终成绩；作废或重赛仍需重新确认。

## 创建赛事三步流程 · 2026-10-25

- 参赛名单、赛制定制、赛程预览分成三个页面，返回时保留草稿与未变更的预览分组。
- 参赛范围合并为男女不限 / 仅男子 / 仅女子；双打先确认搭档。
- 仅保留全员循环、小组后同名次赛、小组后淘汰赛三种赛制，按赛制显示相关控件。
- 排名顺序改为中文选择，计分、季军赛、后续规则和展示名次均附解释。
- 预览显示实际首阶段对阵、分组人数与预计场数，最后确认才保存正式赛事。

## 晋级名单与下一轮对阵列表 · 2026-10-25

- 小组晋级顺序改为可拖拽列表，标注自动统计战绩和晋级线，支持上下移动及恢复统计顺序。
- 下一轮确认统一展示晋级来源与实际对阵，移除甲方/乙方标签。
- 淘汰赛后的对阵位置可拖动交换，决赛胜者与季军赛负者分开显示，轮空明确标注无需记分。
- 小组顺序变更实时重算下一轮建议，管理员仍可明确更换参赛者并记录依据。
- 预览和取消不写正式数据；确认晋级顺序不改写原始战绩，已有后续比分保持完整并提示核查影响。

## 海军蓝主题与比赛进度引导 · 2026-10-25

- 参考提供的 KEAN 标志，采用海军蓝 #0B2D50、浅蓝和白色；同步侧栏、表单、名单拖动、成绩页与导出赛程图。
- 记分默认最新阶段在前，已完成的旧轮次折叠保留。
- 决赛和季军赛完成后自动显示“查看比赛结果”；已存在的末轮引导继续记分或查看结果。
- 合并“统计与晋级”和“赛程示意”为“晋级与赛程”，逐轮切换小组统计、确认名单和实际对阵。
- 晋级、最终成绩确认的说明选填。晋级后显示已保存名单、核对时间、操作者和核对次数。
- 未开打的最新淘汰轮可重新调整原有对阵，不追加重复轮次。已有比分的轮次可再次确认名单，保留比分、后续赛程及已确认成绩。
- 正常使用与旧数据库兼容，无须迁移；新增名单确认记录随赛事包和备份保存。

## 录分停留、赛事取消与问题排序 · 2026-10-25

- 移除录分后的自动回顶，保存重绘与关闭弹窗时按原比赛卡片恢复位置，保留已展开的历史轮次。
- 小组未完赛时只提示统计已更新，末场保存后保留晋级提醒；不主动跳转。
- 新增“取消整届赛事”，确认后移除整届记录，无须先归档；可通过回到上一步恢复。
- 将“撤销”改为“回到上一步”，确认框明确列出将放弃的操作，并恢复此前数据和页面上下文。
- 回退只消耗成功保存的操作，支持最近20次；失败保留历史，重启后通过快照恢复。
- 待改进中的未解决问题按高、中、低优先级排列，已解决问题置底；完成、重新打开和筛选均使用同一排序。

## 简化待改进问题的版本管理 · 2026-10-25

- 移除新增、编辑问题时的“对应版本”输入框和列表中的版本标签，用户无需学习或递增版本号。
- 新增问题内部采用当前程序版本；编辑、完成、重新打开保留旧版本元数据和稳定ID。
- 保留全量备份及问题清单的格式兼容性，不对已有正式数据执行批量迁移。
- 本项独立于上一轮录分、取消恢复和排序改动提交。

## 删除误加的待改进问题 · 2026-10-25

- 在已有问题的编辑弹窗中加入红色“删除”按钮，新增问题时不显示。
- 删除前显示原问题标题并再次确认；取消后保留未保存的编辑内容。
- 根据稳定ID删除一条记录，同名条目不受影响；内置、手动新增、未解决和已解决问题均可删除。
- 删除支持“回到上一步”完整恢复；刷新或恢复已删除状态的备份不会自动加回内置问题。
- 删除不受标题等必填校验影响；回车仍然保存，不会触发删除。

## 公开下载与队员隐私隔离 · 2026-10-27

- 原源码仓库与历史提交保持私有，另设只包含说明和程序包的公开下载仓库，不授予下载者协作者权限。
- 移除硬编码真实队员名单及初始化入口；八人回归示例和测试统一改用虚构编号。
- 正式本机名单和既有赛事不迁移、不改名、不删除；实际名单通过管理员私下提供的备份交接。
- 公开打包改为程序文件允许清单，排除数据库、备份、源码历史、测试和文档截图。
- 比对本机真实姓名、队员ID与联系方式，检查UTF-8/UTF-16LE；命中即拒绝生成公开包。
- 加强Git忽略规则，防止本机数据、会话文件、凭据或维护存档意外入库。
