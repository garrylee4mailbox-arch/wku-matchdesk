**[下载最新 Windows 使用包](https://github.com/garrylee4mailbox-arch/wku-matchdesk-downloads/releases/latest)**

## 第一次使用

1. 打开上方下载页，下载 **Assets** 中名称带有 `Windows` 和 `Public.zip` 的文件。
2. 全部解压到自己的文件夹。
3. 双击 **开始记录比赛.cmd**，浏览器会自动打开比赛系统。

适用于 Windows 10 / 11，无需安装 Git、GitHub Desktop、VS Code、Node.js 或 Python。页面自动生成的 **Source code** 压缩包仅含本下载页的说明，不是运行程序。

## 已有旧版，怎样更新

1. 从右下角系统托盘退出旧程序，并备份原来的 **data** 文件夹。
2. 将新版解压到一个新文件夹。
3. 把旧的 **data** 文件夹复制到新版 **开始记录比赛.cmd** 旁边，再启动。

今后直接打开本页或“最新版本”链接即可获取更新，不需要管理员反复发送压缩包。

## 名单与比赛数据

- 公开包不含真实队员姓名、队员数据库、比赛记录或管理员备份，首次启动为空名单。
- 示例仅使用“虚构选手01”等编号。如需实际名单，由管理员通过私下渠道单独提供备份后导入。
- 比赛数据保存在各自电脑的 **data** 文件夹。此页面只分发程序，不会自动上传或同步名单、比分。
- 请勿把自己的 **data**、备份、成绩文件或含队员信息的截图上传到公开页面。
